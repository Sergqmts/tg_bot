Техническое задание: Система мультитематического агрегатора Telegram-контента с ИИ-рерайтом
1. Общее описание проекта
Создание автоматизированной системы для мониторинга 30 Telegram-каналов (источников), распределенных по 6 тематическим категориям. Система должна извлекать новые публикации, фильтровать рекламу, проверять контент на уникальность, выполнять качественный рерайт текста с помощью ИИ (Groq/Llama 3) и публиковать готовый результат в соответствующие целевые сообщества с сохранением медиафайлов (фото, видео, анимации).
2. Архитектура системы
UserBot (библиотека Pyrogram): Работает через API Telegram (MTProto) для чтения сообщений из закрытых и открытых каналов.
Модуль фильтрации: Двухуровневая очистка контента (жесткие стоп-слова и интеллектуальная фильтрация).
База данных (SQLite): Хранение хэшей опубликованных постов для предотвращения дублирования.
ИИ-обработчик (Groq API): Асинхронное выполнение рерайта текста.
Медиа-процессор: Обработка и пересылка фото, видео (до 2 ГБ) и GIF-анимаций.

4. Технические требования к реализации
4.1. Алгоритм обработки поста
Перехват нового сообщения (текст, фото, видео или GIF).
Проверка на наличие рекламных стоп-слов (erid, реклама, промокод и т.д.).
Генерация MD5-хэша текста и проверка в SQLite.
Отправка текста в Groq API (модель Llama-3.3-70b-versatile).
Промпт: Удаление авторства, призывов к подписке, ссылок на каналы. Сохранение полезных внешних ссылок и форматирования.
Публикация в целевой канал (использование file_id для медиа).
4.2. Безопасность и стабильность
Использование асинхронности (asyncio) для предотвращения блокировок при ожидании ответа от ИИ.
Обработка ошибки 429 (Too Many Requests) от Groq.
Логирование ошибок отправки и рерайта.
5. Стек технологий
Язык: Python 3.10+
Библиотеки: Pyrogram (TG API), Groq (AI API), TgCrypto (ускорение), SQLite3 (БД).
Инфраструктура: VPS на Ubuntu, запуск через PM2 или Systemd.
